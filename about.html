What Tyrone Command Center is

A native desktop application (built with Tauri) that gives one person a single dashboard for the social accounts they already own, plus a local, private AI assistant.

Account Center

The Account Center lets you connect accounts on supported platforms through each platform's own official sign-in flow:

PlatformHow you connectWhat Tyrone can read
YouTubeGoogle OAuth 2.0Your own channel's public/owner-visible stats and analytics (read-only)
TikTokTikTok Login Kit (OAuth 2.0 + PKCE)Basic profile info (name, avatar, ID) for the account you authorize
InstagramMeta Graph API OAuthBasic business-account info and insights for the account you authorize

You can connect more than one account per platform, rename them locally, refresh their status, or disconnect and remove them at any time. Disconnecting revokes Tyrone's access with the platform itself, not just locally.

Local AI assistant

Tyrone includes an optional voice/command layer for quick actions (like refreshing an account or opening an app) and a "Second Brain" feature that indexes a folder of your own Markdown notes (compatible with Obsidian) so the assistant can reference and add to them. Both features run entirely on your own computer — there is no cloud AI backend that receives this data.

What Tyrone Command Center does not do

  • It does not post, message, or take any action on your behalf that you did not explicitly trigger.
  • It does not attempt to automate engagement in a way designed to evade a platform's spam detection, rate limits, or enforcement.
  • It does not claim partnership, endorsement, or verification from TikTok, YouTube/Google, or Meta.
  • It does not guarantee that any connected account is safe from action taken by the platform itself.
